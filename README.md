# 文献综述作业评分器 · 本地版

双击 `index.html` 即可在任意电脑的浏览器中离线使用，**无需安装、无需服务器、无需 API Key**。

## 功能
- **六维评分**：选题与问题意识 / 文献检索与梳理 / 检索与综合方法 / 论证与逻辑 / 创新与价值 / 学术规范与表达（权重按作业类型自动切换，文献综述作业为默认）。
- **文献真实性核验**：自动提取文中的 DOI / PMID，实时比对 CrossRef 与 PubMed 官方数据库；查无记录者判为「疑似伪造」，触发**一票否决**（综合分封顶 49）。
- **AI 使用痕迹检测**：规则层（套话密度、句长均匀度、连接词密度）给出 AI 指数；可选开启「大模型严格评分」（填你自己的 LLM Key）。

## 使用
1. 把学生作业（.docx / .pdf / .md / .txt）拖入虚线框，或直接粘贴正文。
2. 选择作业类型（默认「文献综述作业」）。
3. 点「开始评分」。

## 说明
- 作业正文**不会上传**到任何第三方；仅 DOI/PMID 编号会发往 CrossRef / PubMed 做真伪比对。
- 文献核验建议保留 DOI（CrossRef 跨域支持最佳）；少数浏览器对 PubMed 的跨域请求可能显示「无法核验」，属正常现象，可让学生补充 DOI 后复检。
- PDF 解析需联网加载解析库；离线时请改用 .docx / .txt。
- 「大模型严格评分」为可选项：开启后由你自己提供的 LLM Key 完成，Key 仅存于本机浏览器 localStorage。

## 两人共用
把本文件夹（或 `review-grader-web.zip`）拷贝到两台电脑，各自双击 `index.html` 即可。无需账号、无需联网（文献核验与可选 LLM 除外）。
