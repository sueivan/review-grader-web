文献综述作业评分器 · 本地版

无需 API Key，电脑双击即用；也可在手机浏览器中「添加到主屏幕」当作 App 安装。文献核验 + 六维评分 + AI 痕迹检测全部在本地完成，可离线使用。

使用说明：把学生交来的作业（.docx / .pdf / .md / .txt）拖入下方虚线框，选好作业类型，点「开始评分」。本工具不联网上传你的作业内容到任何第三方——CrossRef / PubMed 仅用于核对文献编号真伪。
